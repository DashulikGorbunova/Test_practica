# Star Squad — игровой чат

Тестовое задание для производственной практики, **вариант B — Frontend**.
Мини-компонент игрового чата на чистых HTML, CSS и JavaScript без сторонних библиотек.

## Демо

Адрес для GitHub Pages: https://dashulikgorbunova.github.io/Test_practica/

Для публикации: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

## Запуск

Скачайте репозиторий и откройте `index.html` в браузере. Все три файла
(`index.html`, `style.css`, `script.js`) должны находиться в одной папке.

Либо запустите локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Установка зависимостей и сборка не требуются.

## Реализовано

- Отправка сообщения кнопкой «Отправить» и клавишей Enter.
- Очистка поля и возврат фокуса после отправки.
- Текущее время отправки каждого сообщения в часовом поясе браузера.
- Проверка пустого ввода, включая строки из пробелов.
- Выбор одного из трёх героев; имя выбранного героя отображается в новых сообщениях.
- Адаптивное оформление в стиле игрового лобби.

Чат работает локально в браузере: сообщения не передаются другим пользователям
и исчезают после обновления страницы. Персонажи — собственные условные герои,
для аватаров используются emoji; ресурсы сторонних игр не используются.

## Структура

- `index.html` — разметка чата, выбор героя и форма ввода.
- `style.css` — оформление, состояния элементов и адаптация для телефона.
- `script.js` — обработка формы, проверка текста и создание сообщений.

Обработчик `submit` обслуживает и кнопку, и Enter. `trim()` убирает пробелы
по краям и позволяет отклонить пустой ввод. Сообщения вставляются через
`textContent`, поэтому пользовательский HTML отображается как обычный текст.

## Проверка

Отправьте текст кнопкой и через Enter: он должен появиться с именем героя и
временем, а поле — очиститься. Пустая строка и пробелы не создают сообщений.
После смены героя новые сообщения подписываются выбранным именем; старые
сохраняют прежнее. Строка `<b>Привет</b>` отображается буквально.
