# Игровой чат — вариант B

Мини-компонент на HTML, CSS и JavaScript без библиотек и зависимостей.

## Запуск

Откройте `index.html` в браузере или выполните в папке проекта:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Возможности

- Отправка сообщения кнопкой «Отправить» или клавишей Enter.
- Очистка поля и возврат фокуса после отправки.
- Время отправки в часовом поясе браузера.
- Пустые сообщения и строки из пробелов не добавляются.
- Сообщения хранятся только на странице и исчезают после обновления.

## Демо на GitHub Pages

В репозитории откройте **Settings → Pages → Deploy from a branch**,
выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
После успешной публикации адрес демо:
https://DashulikGorbunova.github.io/Test_practica/

## Как устроен код

`index.html` — разметка, `style.css` — оформление и адаптация под телефон,
`script.js` — обработчик отправки формы. Он отменяет перезагрузку страницы,
убирает пробелы по краям через `trim()`, проверяет текст и создаёт сообщение
с текущим временем. `textContent` безопасно вставляет текст без выполнения HTML.

## Проверка вручную

Отправьте сообщение кнопкой, затем ещё одно через Enter. Проверьте порядок,
время и очистку поля. Попробуйте отправить пустую строку и пробелы — новых
сообщений быть не должно. Текст `<b>Привет</b>` должен отображаться буквально.

При подготовке проекта использовался ИИ (ChatGPT): генерация кода и проверка.
